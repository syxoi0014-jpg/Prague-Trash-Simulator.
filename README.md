# Prague Trash Simulator: Žižkov Edition 🚛

A 2D top-down simulation game built from scratch using **Java SE**. This project simulates the challenging life of a trash truck driver in the Žižkov district of Prague.

## 🌟 Key Features
* **Smart Rival AI:** Uses a multi-raycasting system for obstacle avoidance and autonomous navigation.
* **Custom Physics Engine:** Features real-time collision detection, momentum, and friction mechanics.
* **Dynamic World:** Includes a day/night cycle, weather effects (rain affecting driving physics), and a functioning traffic system.
* **Career Mode:** Manage fuel, earn money, and compete against an AI rival for the highest score.

## 🛠 Tech Stack
* **Language:** Java 8+
* **Graphics:** Java 2D API (Swing/AWT)
* **Audio:** Java Sound API for immersive SFX.

## 🚀 How to Run
1. Ensure you have **JDK 8** or higher installed.
2. Download all repository files.
3. Place all assets (images and sounds) in the project root folder.
4. Compile and run `PragueTrashSim.java`.
